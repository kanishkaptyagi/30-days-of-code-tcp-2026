Event Details

Event Name Event Description Date Time Venue
The Syntax Sprint(knockout Round) This is the "knockout" round designed to test fundamental problem-solving skills and speed. Format: Multiple Coding Problems and 2-3 short algorithmic challenges. Focus: Data structures, algorithms, and language-specific nuances. Goal: Filter the top 20-30% of participants for the main event. 5th January 2025 10:00 AM - 2:00 PM CCC Building
Debugging Duel(Technical Proficiency) This is the "knockout" round designed to test fundamental problem-solving skills and speed. Format: Participants are given a "broken" project with hidden bugs, memory leaks, or logical errors. Focus:Code comprehension, optimization, and testing. Goal: Ensure participants have the technical maturity to handle complex builds in the later stages. 6th January 2025 10:00 AM - 6:00 PM CCC Building
The Build-a-thon (The Main-Grind) This is the main event where selected participants from the previous rounds compete to build innovative solutions. Format: Team-based project development over 24-48 hours. Focus: Creativity, teamwork, and real-world application development. Goal: Develop a functional prototype or solution that addresses a specific challenge or theme. 7th-8th January 2025 10:00 AM - 9:00 PM CCC Building
Pitch Perfect (Finale & Presentation) This is the final round where teams present their projects to a panel of judges. Format: Each team gets a set time (e.g., 30-45 minutes) to present their project, followed by a Q&A session. Focus: Presentation skills, project impact, and feasibility. Goal: Select winners based on innovation, execution, and presentation quality. 9th January 2025 10:00 AM - 5:00 PM Auditorium, CCC Building
